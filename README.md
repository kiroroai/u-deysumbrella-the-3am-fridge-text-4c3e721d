The one line a smart fridge texts its owner at 3am — the only light still on in the house, and only because its owner keeps opening it to hunt for food already eaten. Built for make.fun's "The 3AM Fridge Text" bounty.

## Run it

```sh
python3 main.py
```

The program writes its single line (125 characters) to `/output/entry.txt`.
